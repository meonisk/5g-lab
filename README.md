# 5g-lab — звонки и голосовой перевод в сети 5G

Проект объединяет **IMS-телефонию и обработку речи**: звонки между абонентами,
перевод русского и английского, голосовой ответ, запись и расшифровку по запросу.
Распознавание, перевод и синтез речи выполняются локально.

Для проверки используется собственное ядро **OAI CN5G** и эмуляторы абонентов.
Партнёрам передаётся **IMS + AI**, которая подключается к их существующему ядру.

**Первый раз в проекте?** Начните с [знакомства со стендом](docs/first-use.md):
что здесь запускается, как проверить первый вызов и где найти расшифровку.
Управление выполняется через терминал; веб-интерфейса звонков нет.

## Запуск

Нужны Git, Python 3.12+ и Docker с Linux-контейнерами. На Windows также нужны
WSL2 и Git Bash. Первый запуск скачивает образы и модели и выполняет тестовые звонки.

Используйте ветку **`master`**. Выберите один сценарий:

- **Локальный стенд / одна ВМ:** [установка OAI + IMS + AI](docs/quickstart.md).
- **Без видеокарты:** [режимы baseline / balanced / compact / minimal](docs/cpu-ai-profiles.md).
  `compact` использует Whisper base + OPUS-MT + Piper; обычный запуск сохраняет Qwen.
- **У партнёров уже есть OAI:** [развёртывание только IMS + AI](docs/partner-integration.md).

Публичные настройки: [app/config/lab.env](app/config/lab.env),
[полный справочник параметров](docs/lab-env-reference.md). Секреты создаются отдельно.

## Возможности и интеграция

| Вопрос | Ответ и подробности |
| --- | --- |
| У нас архитектура 3GPP IMS? | Есть P/I/S-CSCF, HSS/Cx и AS/ISC; это лабораторный профиль, не полная сертификация. [Границы архитектуры](docs/integration-contract.md) |
| Можно связать IMS с OAI другого проекта? | Да, через IMS DNN, маршрутизацию, DNS/P-CSCF и SIP/RTP. [Интерфейсы подключения](docs/integration-contract.md) |
| IMS и Python-переводчик в контейнерах? | Уже разделены на сервисы. На одной ВМ запускается локальный стенд; ресурсный бюджет всей ВМ ещё нужно измерить. [Развёртывание](docs/quickstart.md) |
| Есть отдельная передаваемая часть? | Есть `compose.partner.yml` без OAI/RAN/UE. Отдельный репозиторий ещё не выделен. [Состав и порядок передачи](docs/publication.md) |
| Заработает настоящий телефон? | Пока не подтверждено: нужны конкретные телефон, SIM и RAN. [Проверки телефона](docs/native-phone.md) |
