# 5g-lab — IMS и голосовой перевод для сети 5G

Стенд добавляет к работающему ядру 5G **OAI CN5G** телефонную связь (IMS) и голосовые
услуги: звонки между абонентами, перевод речи русский ↔ английский, запись и
расшифровку разговора. Распознавание, перевод и синтез речи работают локально, без
облака.

Ядро 5G, радиосеть и SIM-карты — ваши. Стенд ставит рядом с ядром свои контейнеры и
подключает их к Docker-сети ядра.

## Быстрый запуск

Нужно: Linux, Docker Engine 28+ с Compose 2.33+, Python 3.11+, запущенное ядро OAI.

```bash
git clone --branch partner-ims-ai https://github.com/meonisk/5g-lab.git
cd 5g-lab
scripts/core-setup.sh apply   # один раз: настроить ядро OAI под IMS
scripts/setup.sh              # модели перевода + запуск всех контейнеров
scripts/verify-all.sh         # все проверки по порядку, итог PASS/FAIL
```
