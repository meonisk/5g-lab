## Обозначения

| Обозначение | Значение в этом проекте |
| --- | --- |
| OAI CN5G | Реализация ядра сети 5G от OpenAirInterface |
| IMS | Подсистема регистрации и управления телефонными вызовами |
| AI | Наши сервисы распознавания, перевода и синтеза речи |
| UE / gNB | Абонентское устройство / базовая станция; локально используются эмуляторы |
| SIP / RTP | Сигнализация звонка / передача звука |
| STT / TTS | Распознавание речи / синтез речи из текста |
| PASS / FAIL / UNVERIFIED | Проверка пройдена / не пройдена / результат не проверен |

Имена команд, параметров и протоколов сохраняются, чтобы их можно было найти
в коде и журналах. Технические планы и архивы могут содержать прежние названия
этапов; они не обозначают готовность текущего стенда.
