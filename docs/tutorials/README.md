# Туториалы

Три основных документа проекта. Их достаточно, чтобы поднять стенд, подключить
IMS + AI к уже работающему ядру 5G и разобраться, как всё устроено.

| Туториал | О чём |
| --- | --- |
| [1. Настройка IMS и её связь с ядром](guide-1-ims-core.md) | Локальное ядро OAI + IMS; подключение IMS + AI + SIP к ядру партнёров: что поменять в их OAI, что заполнить у нас, проверка каждого шага вызова |
| [2. Связь IMS и AI](guide-2-ims-ai.md) | Как вызов попадает в AI, номера услуг, режимы с Qwen и без GPU, запуск, проверка, настройка, задержка |
| [3. SIP-серверы и клиенты](guide-3-sip.md) | Kamailio P/I/S-CSCF, PyHSS, RTPengine, DNS; клиенты PJSUA и SIPp AKA; внешний клиент и телефон |

Каждый туториал состоит из двух частей:

- **Часть 1 — только команды.** Выполните по порядку и получите результат.
- **Часть 2 — разъяснения.** Что запущено, как устроено, как настроить и починить.

Порядок чтения: 1 → 2 → 3. Если ядро уже работает у партнёров, начните с
[туториала 1, вариант Б](guide-1-ims-core.md#б-ядро-уже-работает-у-партнёров-ставим-только-ims--ai).

Остальные документы в [docs/](../README.md) — справочники и история; туториалы
ссылаются на них только за подробностями.
