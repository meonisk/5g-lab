# Проверки

[Назад к карте app](../README.md).

| Папка | Что проверяет | Что требуется |
| --- | --- | --- |
| [unit](unit) | Поведение модулей и конфигурации без живого стенда | Python и зависимости разработки |
| [integration](integration) | Регистрация, звонки, RTP, AI, восстановление | Запущенный Docker-стенд |
| [fixtures](fixtures) | Синтетические сценарии и Compose-профили тестов | Используются проверками |

Из корня репозитория `python scripts/quality/check.py` запускает offline-проверки:
код, документацию, Git-гигиену и unit-тесты.

Интеграционные проверки выполняйте **последовательно**: они используют один
стенд, создают звонки и могут перезапускать сервисы. Начните с
[порядка запуска](../../docs/running.md). AMR/AMR-WB проверяет
[verify_phone_codecs.py](integration/verify_phone_codecs.py), а серверные
предпосылки работы телефона — [phone_readiness.py](../../scripts/phone_readiness.py).

Успешный тест эмулятора не подтверждает работу настоящего телефона.
См. [native-phone.md](../../docs/native-phone.md) и [статус](../../docs/status.md).
Записи, трассы и отчёты сохраняются в `local/`, а не в этих папках.
